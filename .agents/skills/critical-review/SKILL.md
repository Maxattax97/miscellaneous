# Critical Review

1. Establish the intended behavior and review the complete diff in context.
2. Trace changed paths, failure modes, boundary cases, and compatibility impacts.
3. Check tests, error handling, data validation, access control, and sensitive-data exposure.
4. Prioritize concrete findings by severity, including file locations and rationale.
5. Distinguish verified issues from questions, and state what was checked successfully.
